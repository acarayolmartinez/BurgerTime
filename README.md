# BurgerTime para ZX Spectrum

Conversión del arcade BurgerTime para ZX Spectrum 128K, desarrollada en C con z88dk.

## Objetivo

Crear una versión jugable inspirada en el arcade original, con Peter Pepper, enemigos, plataformas, escaleras e ingredientes de hamburguesas.

## Plataforma y tecnología

- ZX Spectrum 128K como objetivo inicial.
- C con z88dk.
- Gráficos previstos con Nirvana+.
- Diseño modular para facilitar una posible adaptación posterior a 48K.

## Estado

Proyecto en fase inicial. La estructura y las mecánicas se irán implementando progresivamente.
